# Aplicações Web – HTML / PWA

Este repositório contém aplicações web desenvolvidas em HTML, CSS e JavaScript,
com foco em experiências interativas e Progressive Web Apps (PWA).

## 📂 Projetos incluídos

- **POLAR_BRINQUE_PWA.html**
  - Aplicação PWA para gestão e visualização de serviços

## 🚀 Como usar

1. Baixe ou clone o repositório
2. Abra o arquivo `.html` em qualquer navegador moderno
3. Para PWA, utilize navegador compatível (Chrome/Edge)

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript puro (Vanilla JS)

## 📱 Compatibilidade

- Desktop
- Mobile
- Android (Termux / WebView)
